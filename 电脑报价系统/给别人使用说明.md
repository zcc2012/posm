# 电脑报价系统使用说明

## Windows

双击：

```text
Windows一键启动.bat
```

首次运行会自动创建本地运行环境并安装依赖。如果电脑没有 Python，脚本会尝试用 Windows 自带的 winget 自动安装 Python。

## Mac

双击：

```text
苹果电脑一键启动.command
```

首次运行会自动创建本地运行环境并安装依赖。如果电脑没有 Python 3，脚本会尝试用 Homebrew 安装；如果电脑也没有 Homebrew，会打开 Python 下载页面。

## 访问地址

启动成功后浏览器会自动打开：

```text
http://127.0.0.1:5000
```
