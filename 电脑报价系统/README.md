# 电脑报价系统

一个基于Flask的电脑配件报价管理系统，支持材料管理、工艺管理、模具管理和报价单生成。

## 🚀 快速开始

### 首次使用
1. **安装依赖**：双击 `安装依赖.bat`
2. **启动系统**：双击 `一键启动.bat`
3. **开始使用**：系统会自动在浏览器中打开

### 日常使用
直接双击 `一键启动.bat` 即可。

## ✨ 主要功能

- **材料管理**：管理各种电脑配件材料信息
- **工艺管理**：管理加工工艺和定价标准
- **模具管理**：管理模具信息和成本计算
- **报价单生成**：自动计算并生成专业报价单
- **客户管理**：管理客户信息和历史报价
- **成本分析**：详细的成本构成分析

## 🔧 系统要求

- Windows 操作系统
- Python 3.7 或更高版本
- 现代浏览器（Chrome、Firefox、Edge等）

## 📊 计算逻辑

### 材料计算
- 公式：(长+30) × (宽+30) ÷ 1,000,000 × 平方单价
- 单位：长宽为毫米，结果为人民币

### 印刷计算
- 3000件以内：固定基础价格（根据尺寸：1000/1500/2000元）
- 超过3000件：基础价格 + 超量部分 × 平方单价 × 面积

### 模具计算
- 公式：基础价格 + 项目套数 × 数量 × 单价
- 基础价格：1000元

## 🛠️ 故障排除

### 常见问题

**Q: 双击启动文件没有反应？**
A: 请确保已安装Python环境，可以先运行 `安装依赖.bat`

**Q: 浏览器显示无法访问？**
A: 请检查5000端口是否被占用，或等待几秒钟让服务完全启动

**Q: 数据丢失了怎么办？**
A: 数据保存在 `quotation_system.db` 文件中，请定期备份此文件

### 技术支持

如遇到技术问题，请检查：
1. Python环境是否正确安装
2. 依赖包是否完整安装
3. 防火墙是否阻止了程序运行
4. 端口5000是否被其他程序占用
