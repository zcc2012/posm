## 计算公式验证

### 标准计算流程
```
1. 面积计算: (长度+30) × (宽度+30) ÷ 1000000 = 面积(m²)
2. 材料成本: 面积 × 材料平方价格 = 材料成本(元/件)
3. 基础费用公摊: 工艺基础价格 ÷ 数量 = 基础费用(元/件)
4. 平方费用: 面积 × 工艺平方价格 = 平方费用(元/件)
5. 总单价: 材料成本 + 基础费用 + 平方费用 = 总单价(元/件)
6. 总价: 总单价 × 数量 = 总价(元)
```

### 实际验证案例
**测试用例**: 印刷+模切，300×200mm，1000件
- 面积: (300+30) × (200+30) ÷ 1000000 = 0.075900m²
- 基础费用: 300.0元 ÷ 1000件 = 0.300000元/件
- 平方费用: 0.075900m² × 0.25元/m² = 0.018975元/件
- 总单价: 0.300000 + 0.018975 = 0.318975元/件
- 总价: 0.318975元/件 × 1000件 = 318.98元
