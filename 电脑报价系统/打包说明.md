# 报价系统使用说明

## 快速开始

### 第一次使用
1. 双击 `安装依赖.bat` 安装必要的Python包
2. 安装完成后，双击 `一键启动.bat` 启动系统

### 日常使用
直接双击 `一键启动.bat` 即可启动系统，会自动打开浏览器。

## 启动方式说明

### 方法一：一键启动（推荐）
- 文件：`一键启动.bat`
- 特点：自动启动服务并打开浏览器，用户体验最佳
- 使用：双击文件即可，关闭窗口自动停止服务

### 方法二：传统启动
- 文件：`启动报价系统.bat`
- 特点：启动服务但不自动打开浏览器
- 使用：双击启动，手动访问 http://127.0.0.1:5000

## 方法二：打包成独立可执行文件

如果您希望创建一个完全独立的可执行文件，可以按照以下步骤操作：

### 安装打包工具
```bash
pip install auto-py-to-exe
```

### 启动图形化打包工具
```bash
auto-py-to-exe
```

### 打包配置
1. **Script Location**: 选择 `app.py` 文件
2. **Onefile**: 选择 "One File" 生成单个exe文件
3. **Console Window**: 选择 "Console Based" 显示控制台
4. **Additional Files**: 添加以下文件夹：
   - `templates` 文件夹
   - `quotation_system.db` 数据库文件
5. **Advanced**: 
   - 在 "--add-data" 中添加：
     - `templates;templates`
     - `quotation_system.db;.`

### 使用PyInstaller命令行（高级用户）
```bash
pyinstaller --onefile --add-data "templates;templates" --add-data "quotation_system.db;." app.py
```

## 注意事项

1. **数据库文件**: 打包后的exe文件会将数据库文件包含在内，但运行时会在exe文件所在目录创建数据库副本
2. **模板文件**: 所有HTML模板文件都会被包含在exe文件中
3. **端口占用**: 确保5000端口未被其他程序占用
4. **防火墙**: 首次运行可能需要允许程序通过防火墙

## 推荐使用方法一

对于日常使用，推荐使用批处理文件方式，因为：
- 启动速度更快
- 文件体积更小
- 更新维护更方便
- 可以实时查看运行日志
