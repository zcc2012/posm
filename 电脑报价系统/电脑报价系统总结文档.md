# 电脑报价系统总结文档

## 系统概述
这是一个基于Flask的Web报价系统，主要用于印刷、切割、模切等工艺的成本计算和报价管理。系统采用SQLite数据库存储数据，具备完整的材料管理、工艺管理、标准管理和报价计算功能。

## 核心功能模块

### 1. 材料管理
- **主要材料**：管理各种印刷材料的基础信息、规格、单价等
- **辅助材料**：包装材料、配件等辅助物料管理
- **材料分类**：支持按类型、规格进行分类管理

### 2. 工艺管理
- **印刷工艺**：支持不同尺寸和数量的印刷标准
- **切割工艺**：精密切割的成本计算
- **模切工艺**：模具制作和模切加工
- **后道工艺**：覆膜、光油、装订等后续处理

### 3. 判定标准管理
- **印刷标准**：基于尺寸和数量的机器类型判定
- **切割标准**：切割工艺的成本标准
- **模切标准**：模切工艺的判定规则
- **损耗标准**：基于数量区间的固定损耗数量
- **纸类材料标准**：卡纸和坑纸的特殊计算标准

## 计算方法详解

### 1. 普通材料计算公式
```
总价 = (材料成本 + 工艺成本) × 数量 × 项目套数
```

#### 材料成本计算
```
材料成本 = ((长度+30) × (宽度+30) ÷ 1,000,000) × 材料平方单价
```
- 长宽单位：毫米(mm)
- 加30mm是考虑加工余量
- 转换为平方米进行计算

#### 工艺成本计算
根据工艺类型采用不同算法：

**印刷工艺：**
- 基础成本：基础价格 ÷ 总数量
- 超量成本：数量>3000时，增加面积×平方价格

**模切/切割工艺：**
```
工艺成本 = 面积 × 工艺平方单价
```

**模具工艺：**
```
工艺成本 = (基础费用 ÷ 总数量) + (面积 × 模具平方单价 × 项目数量)
```

**覆膜/光油工艺：**
```
工艺成本 = (基础价格 ÷ 总数量) + (面积 × 平方价格)
```

### 2. 纸类材料特殊计算
对于卡纸和坑纸材料，采用特殊公式：
```
单价 = (项目套数 × 数量 + 判定标准额外数量) × 材料单价 ÷ (项目套数 + 数量)
总价 = 单价 × 数量
```

### 3. 损耗计算
基于数量区间的固定损耗：
- 小批量(1-500件)：固定损耗50件
- 中批量(501-2000件)：固定损耗80件
- 大批量(2001+件)：固定损耗100件

## 判定逻辑体系

### 1. 印刷标准判定
基于尺寸范围自动选择机器类型：

| 机器类型 | 长度范围(mm) | 宽度范围(mm) | 基础价格(元) | 平方价格(元/㎡) |
|---------|-------------|-------------|-------------|---------------|
| 4开机器 | 0-719 | 0-519 | 600 | 0.15 |
| 对开机 | 720-1019 | 520-719 | 1000 | 0.25 |
| 全开机 | 1020-1419 | 720-1019 | 1500 | 0.30 |
| 大全开 | 1420-1620 | 1020-1220 | 2000 | 0.35 |
| 大幅面印刷 | >1620 | >1220 | 2000 | 0.40 |

### 2. 材料类型判定
- **普通材料**：使用标准计算公式
- **纸类材料**：检测材料名称包含"纸"且为"卡纸"或"坑纸"时，使用特殊公式

### 3. 数量区间判定
系统根据订单数量自动匹配相应的标准：
- 小批量、中批量、大批量有不同的成本结构
- 超过3000件的印刷订单会触发额外的平方价格计算

### 4. API匹配逻辑
系统通过API接口进行标准匹配：
```
匹配参数：工艺名称、材料名称、长度、宽度、数量
匹配结果：返回最适合的判定标准和计算参数
```

## 系统特色功能

### 1. 动态标准管理
- 支持在线添加、编辑、删除各类判定标准
- 实时生效，无需重启系统
- 支持启用/禁用状态管理

### 2. 多套数支持
- 支持项目套数概念，一个项目可包含多套相同产品
- 自动计算套数对成本的影响

### 3. 智能匹配
- 自动根据输入参数匹配最合适的判定标准
- 未匹配到标准时使用默认计算逻辑
- 显示匹配到的标准信息供用户确认

### 4. 成本透明化
- 详细显示材料成本、工艺成本的计算过程
- 提供计算公式和参数的完整日志
- 支持成本明细查看

## 技术架构
- **后端**：Python Flask框架
- **数据库**：SQLite
- **前端**：HTML + Bootstrap + JavaScript
- **API**：RESTful接口设计
- **部署**：支持本地部署和打包为exe文件

## 使用说明

### 1. 系统启动
1. 双击运行`一键启动.bat`
2. 或在命令行执行`python app.py`
3. 浏览器访问`http://localhost:5000`

### 2. 基本操作流程
1. **材料管理**：添加和维护材料信息
2. **工艺管理**：配置各种工艺参数
3. **标准管理**：设置判定标准和计算规则
4. **创建报价**：输入项目参数，系统自动计算价格
5. **查看报价**：生成详细的报价单

### 3. 报价计算步骤
1. 选择材料和工艺
2. 输入尺寸和数量
3. 系统自动匹配判定标准
4. 计算材料成本和工艺成本
5. 生成最终报价

## 注意事项

### 1. 数据备份
- 定期备份`quotation_system.db`数据库文件
- 重要配置修改前建议先备份

### 2. 标准配置
- 印刷标准的修改需要特别谨慎
- 建议在测试环境验证后再应用到生产环境

### 3. 性能优化
- 大量数据时建议定期清理历史记录
- 复杂计算可能需要一定处理时间
