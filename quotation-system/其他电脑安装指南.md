# 报价系统 - 其他电脑安装指南

## 方法一：使用Python环境（推荐）

### 前提条件
1. 安装Python 3.7或更高版本
   - 访问 [Python官网](https://www.python.org/downloads/) 下载并安装
   - 安装时勾选「Add Python to PATH」选项

### 安装步骤
1. 将整个「电脑报价系统」文件夹复制到目标电脑
2. 双击运行「安装依赖.bat」文件
   - 这将自动安装所需的Python包
3. 安装完成后，双击「一键启动.bat」启动系统
   - 系统会自动在浏览器中打开

### 常见问题
- **问题**: 双击「安装依赖.bat」提示找不到Python
  **解决**: 确认Python已正确安装并添加到PATH环境变量
- **问题**: 启动时提示端口被占用
  **解决**: 关闭占用5000端口的其他程序，或修改app.py中的端口号

## 方法二：打包成独立可执行文件

如果目标电脑没有Python环境，或希望提供更简单的使用方式，可以将系统打包成独立的exe文件。

### 打包步骤（在您的电脑上操作）
1. 安装打包工具
   ```
   pip install auto-py-to-exe
   ```

2. 启动图形化打包工具
   ```
   auto-py-to-exe
   ```

3. 在打包工具中设置：
   - **Script Location**: 选择 `app.py` 文件
   - **Onefile**: 选择 "One File" 生成单个exe文件
   - **Console Window**: 选择 "Console Based" 显示控制台
   - **Additional Files**: 添加以下文件：
     - `templates` 文件夹
     - `quotation_system.db` 数据库文件
   - **Advanced**: 
     - 在 "--add-data" 中添加：
       - `templates;templates`
       - `quotation_system.db;.`

4. 点击「CONVERT」按钮开始打包
5. 打包完成后，在output文件夹中找到生成的exe文件

### 在目标电脑上使用
1. 将生成的exe文件复制到目标电脑
2. 双击exe文件运行
3. 在浏览器中访问 http://127.0.0.1:5000

### 注意事项
- exe文件体积较大（约100-200MB）
- 首次运行可能需要允许通过防火墙
- 数据库文件会在exe所在目录创建

## 方法三：创建便携式Python环境（高级）

如果您希望避免在目标电脑上安装Python，同时又不想使用体积较大的exe文件，可以创建便携式Python环境。

### 创建步骤
1. 安装virtualenv
   ```
   pip install virtualenv
   ```

2. 在报价系统文件夹中创建虚拟环境
   ```
   cd 电脑报价系统
   virtualenv venv
   ```

3. 激活虚拟环境并安装依赖
   ```
   venv\Scripts\activate
   pip install -r requirements.txt
   ```

4. 创建启动脚本 `便携式启动.bat`，内容如下：
   ```
   @echo off
   chcp 65001 >nul
   title 报价系统（便携版）
   color 0A
   echo ========================================
   echo           报价系统启动器（便携版）
   echo ========================================
   echo.
   echo 正在启动报价系统服务...
   echo.

   REM 启动Python服务（后台运行）
   start /B venv\Scripts\python app.py

   REM 等待服务启动
   echo 等待服务启动中...
   timeout /t 3 /nobreak >nul

   REM 自动打开浏览器
   echo 正在打开浏览器...
   start http://127.0.0.1:5000

   echo.
   echo ========================================
   echo 报价系统已启动！
   echo 访问地址: http://127.0.0.1:5000
   echo ========================================
   echo.
   echo 提示：
   echo - 关闭此窗口将停止报价系统服务
   echo - 如需重启系统，请关闭此窗口后重新运行
   echo.
   echo 按任意键退出并停止服务...
   pause >nul

   REM 结束Python进程
   taskkill /f /im python.exe >nul 2>&1
   echo 服务已停止。
   ```

### 在目标电脑上使用
1. 将整个文件夹（包含venv目录）复制到目标电脑
2. 双击 `便携式启动.bat` 运行系统

### 优点
- 不需要在目标电脑上安装Python
- 文件体积比exe小
- 启动速度快
- 便于更新维护

## 总结

| 方法 | 优点 | 缺点 | 推荐场景 |
|------|------|------|----------|
| Python环境 | 简单，维护方便 | 需要安装Python | 长期使用 |
| 独立exe | 无需安装Python | 文件体积大 | 临时使用 |
| 便携式环境 | 无需安装Python，体积适中 | 设置复杂 | 多台电脑使用 |
